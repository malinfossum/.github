# Security policy

This covers every public repository under [malinfossum](https://github.com/malinfossum) that has no security policy of its own.

## Reporting a vulnerability

Please don't open a public issue. Report it privately instead: go to the repository's **Security** tab and choose **Report a vulnerability**. Only I can see the report.

Tell me what you found, how to reproduce it, and what an attacker could do with it.

A fork holds someone else's code. Report a problem in a fork to the upstream project, through its own security policy.

## What to expect

I build these projects on my own, so I can't promise fixed response times. I aim to reply within a week and keep you posted while I work on a fix. Fixes land on the default branch, and in a new release where the project has releases. Archived repositories are read-only and get no fixes.

When it's fixed, I'll credit you in the advisory unless you'd rather stay anonymous.

Thanks for helping keep my projects safe.
